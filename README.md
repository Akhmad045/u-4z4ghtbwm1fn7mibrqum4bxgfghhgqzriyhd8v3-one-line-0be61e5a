## The line

> My smartwatch congratulated me on 10,000 steps. I'd spent the whole day hunting for the TV remote.

98 characters, one line, whole enough to land on its own: fitness praise for peak couch behaviour.

## How it works

`main.py` writes the line to `/output/entry.txt` (no trailing newline, so the
file is exactly the 98-byte line). It validates the line against the bounty
gate first — 1 to 140 characters, not only whitespace, a single line — and
`python3 main.py --self-test` proves the write round-trips byte-identically.

```sh
python3 main.py --self-test
python3 main.py                 # writes /output/entry.txt
```
